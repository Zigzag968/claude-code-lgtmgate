# Code map

One line per file. Target: generated by a script from one header per file and checked in CI; until then, whoever adds a file adds its line here. Principles and invariants: `ARCHITECTURE.md`. Direction: `VISION.md`.

## Root
- `VISION.md` — direction read by every agent (CLAUDE.md import): target, who it serves, Never (R1), design decisions, out of scope, Sam's mandate
- `ARCHITECTURE.md` — imported by Sam and Morgan: numbered constraints with their checks, one-way doors, where new code goes, declared exception
- `CLAUDE.md` — runbook for the Lead: three binding rules, launching and supervising a run
- `CONTRIBUTING.md` — how to contribute: ways to help, review expectations, code of conduct link
- `MAINTAINING.md` — maintainer runbook: dev loop, release/rollback, trust model of the delivery channel
- `README.md` — project pitch, animated header, install and usage for the lgtmgate plugin
- `SECURITY.md` — how to report a vulnerability via private GitHub advisory

## docs/
- `docs/architecture-notes.md` — sections moved out of VISION.md and ARCHITECTURE.md to fit their budgets, never imported
- `docs/codemap.md` — one line per tracked file, purpose summary (this file)
- `docs/critical-paths.md` — the use cases that must work at every release, each with its proof
- `docs/supervision.md` — reference for supervising in-flight pipeline runs, the full mechanism

## workflows/
- `workflows/deliver-pipeline.js` — the engine: stages, statuses, all agent calls through `callAgent`

## scripts/
- `scripts/cleanup-worktree.sh` — sanctioned removal of a merged, clean pipeline worktree
- `scripts/gen-readme-header.mjs` — generates the README's animated SVG header (assembly lines, LGTM gate)
- `scripts/guards.cjs` — CI guards: R1 ratchet vs origin/main, all-tests-wired, sam-parity, version floor, doc-budgets
- `scripts/lead-merge.sh` — the only merge path: re-checks the checklist, bumps the version, merges
- `scripts/lib/acceptance-check.sh` — shared acceptance-checklist check, sourced by the merge hook and lead-merge
- `scripts/provision_worktree.sh` — symlinks unversioned deps (.env, venvs, caches) into a new worktree
- `scripts/redact-fixture.cjs` — redacts a fixture file before commit, fixed replacement rule list
- `scripts/run-flow-suite.cjs` — offline runner for the deliver-pipeline flow test suite
- `scripts/run-offline.cjs` — replays raw run fixtures through the real parsers offline
- `scripts/run-workflow-headless.sh` — deterministic proof channel for a headless Workflow run in --print mode
- `scripts/test-cleanup-worktree.sh` — regression test for cleanup-worktree.sh, fake gh, temp repo
- `scripts/test-guards.sh` — regression test for guards.cjs across its env seams and cases
- `scripts/test-lead-merge.sh` — regression test for lead-merge.sh with a fake gh and throwaway repo
- `scripts/test-run-offline.sh` — self-test of run-offline.cjs against the committed smoke fixtures
- `scripts/test-verify-workflow-launch.sh` — regression test for verify-workflow-launch.sh's exit-code contract
- `scripts/verify-workflow-launch.sh` — mechanical post-launch health check for a Workflow run's transcript

## hooks/
- `hooks/SessionStart/inject_stub.py` — SessionStart hook: injects a short lgtmgate status stub into context
- `hooks/Stop-supervise-runs.sh` — Stop hook: watchdog nudging pipeline runs left silently stuck
- `hooks/SubagentStop-worktree-cleanup.sh` — SubagentStop hook: warns only, never deletes a worktree
- `hooks/block-merge-unchecked.sh` — PreToolUse hook: refuses `gh pr merge` while acceptance boxes are unchecked
- `hooks/deny-destructive-git.sh` — PreToolUse hook: denies destructive git operations for all agent sessions
- `hooks/lib-worktree-root.sh` — sourced helper: resolves the worktree root from config precedence
- `hooks/plugin-hooks.json` — hook registration manifest wiring the plugin's SessionStart/Stop/PreToolUse hooks
- `hooks/test-Stop-supervise-runs.sh` — regression test for Stop-supervise-runs.sh, false- and true-positive cases
- `hooks/test-SubagentStop-worktree-cleanup.sh` — regression test for the worktree-cleanup warning hook
- `hooks/test-block-merge-unchecked.sh` — regression test for block-merge-unchecked.sh, open/checked box cases
- `hooks/test-deny-destructive-git.sh` — regression test for deny-destructive-git.sh, remote-branch-delete equivalents

## commands/
- `commands/deliver.md` — /lgtmgate:deliver runbook: Lead launches and supervises the delivery pipeline
- `commands/init.md` — /lgtmgate:init runbook: bootstraps the plugin's config into a project

## agents/
- `agents/mia.md` — Mia (PM): drafts acceptance criteria and success metrics from tracked analytics
- `agents/morgan.md` — Morgan (Reviewer): reviews Nick's PR against the plan and conventions
- `agents/nick.md` — Nick (Dev): implements Sam's plan with tests, opens a draft PR
- `agents/sam.md` — Sam (Scout & Planner): scans the codebase, posts an anchored implementation plan
- `agents/theo.md` — Theo (Diagnose): reproduces a claimed cause before Sam plans, describe-only
